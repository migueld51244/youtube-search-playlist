YouTube Playlist Searcher

Be able to use a search box inside your playlists!

At last!

Works on Watch Later or any playlist you encounter!

How to start using it?

Just open up a YouTube playlist that a search box like this will appear:

Then, start typing! As you type, the matching video will appear.

If more than one matches, you can select them with the arrows:

Disclaimer

You won't be able to search the entire playlist at once, since YouTube uses a feature called "Lazy Loading". This only loads the first 100 videos and as you scroll, it loads another more 100
